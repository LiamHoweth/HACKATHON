# Agent notes

- The app is **Still Here**, a conversation-first AAC prototype (Next.js 16.4 App Router, React 19.3, TypeScript, zod 4, `@anthropic-ai/sdk` 1.3, vitest 5). Commands: `npm run dev` · `npm test` · `npm run typecheck` · `npm run lint` · `npm run build` · `npm run check`.
- `AGENTS.md` is the shared AI policy. `CLAUDE.md` imports it and adds Still Here invariants and boundaries. Copilot's entry file points to `AGENTS.md`.
- Architecture: `src/core/reducer.ts` makes every decision. `src/core/targets.ts` (`targetsFor`) is the only target registry, and every input goes through `ACTIVATE`. Browser effects run once each in `src/runtime/effects-runner.ts`. Details are in `docs/ARCHITECTURE.md`.
- Live AI: `AI_PROVIDER=openai`, `OPENAI_API_KEY`, `REPLY_MODEL=gpt-6-astra`, with transcription by `gpt-transcribe`. These are set in the git-ignored `.env.local` and in Railway variables. Both were verified live with synthetic inputs on 2026-10-24. The Anthropic adapter exists but is unverified.
- Deployment: Railway project `still-here`, service `api`, at https://api-production-18038.up.railway.app (deployment `f65385bb` = commit `5de1a57`, 12:13 CT). Deploy with `railway up --service api`; a Git push does not deploy. Live AI, transcription, and `/api/speech` require the `x-still-here-access` header. The access code is in Railway variables and the git-ignored `.env.railway.local`; **never print, log, or paste it**. Only wrong non-empty codes count toward the throttle and a correct code always passes (uncommitted fix, D36); HSTS is also uncommitted. Both are pending a redeploy. Runbook: `docs/DEPLOYMENT.md`.
- Current brief: iPad Safari, default access mode **`brow-blink`**: eyebrow raise held for the calibrated 0.35–0.5 s = NEXT, keep holding = another NEXT every 600 ms, deliberate jaw drop = BACK, long blink = SELECT. Fast mode (default at setup) speaks a suggestion on one selection; with it off, review starts on Cancel and a new blink confirms. Branching ("Other ways to answer", default on at setup): 2 replies + 3–5 AI directions; directions' replies are prefetched. MediaPipe Face Landmarker runs locally (`public/models`, `public/wasm`; model Apache-2.0, not for life-critical decisions). Pure logic: `src/access/{blink,brow}-*.ts`; `src/access/gesture-arbiter.ts` is the only emitter of accepted commands; `src/runtime/useBlink.ts` is the adapter. Everything goes through the same guarded `ACTIVATE`. Nothing is verified on a physical iPad or real camera.
- ElevenLabs (implemented, live **not verified**: no key): server-only adapter in `src/server/elevenlabs/` (see its README), `POST /api/speech`, `GET /api/voices`. Env names: `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID`, `ELEVENLABS_MODEL_ID` (default `eleven_v4_turbo`), `ELEVENLABS_TRANSPORT` (`ws`/`http`), `ELEVENLABS_OUTPUT_FORMAT`, `ELEVENLABS_TIMEOUT_MS`, `ELEVENLABS_ALLOWED_VOICE_IDS`, `ELEVENLABS_DAILY_CHAR_BUDGET`. Make no zero-retention claim for ElevenLabs or OpenAI. The basic device voice is a labeled fallback that needs a new review and confirmation.
- `/trial` (`src/app/trial/`, `src/components/trial/`, uncommitted at 12:30) is the engineering gesture-trial recorder. It never dispatches app actions and is labeled "not clinical validation".
- `ios/` holds an experimental SwiftUI client (xcodegen). It is outside the demo path.
- `docs/PROJECT_BRIEF.md` owns event facts and team decisions. `docs/PROGRESS.md` owns current status. `docs/TEST_RESULTS.md` records only executed checks. `docs/PRESENTATION_NOTES.md` is the running, append-only pitch log (tag entries VERIFIED / SYNTHETIC / NOT YET). `docs/REFERENCES.md` holds prior art and provider-doc checks.
- CI: `Repository hygiene` (links, sensitive filenames, whitespace) and `App checks` (typecheck, lint, test, build). The API tests mock the Anthropic SDK.
